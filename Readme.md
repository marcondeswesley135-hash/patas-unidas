# Instituto Patas Unidas

Um site para o resgate e adoção de animais em perigo e maus tratos  

## Páginas do site

- Doação serve  para ajuda no projeto 
- Adote um pet serve para quem quer adotar um animal resgatado
- Seja voluntário serve para você ser voluntário e ajudar a resgatar animais

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript
## Como abrir o projeto

Baixe o projeto, abra a pasta no VS Code e abra o arquivo html/index.html com o Live Server.
